# MyPortfolio

Interactive portfolio/resume app built with React, TypeScript, Vite, shadcn-ui, and Tailwind CSS.

## Local development

### Option 1: Node.js + npm

```sh
npm install
npm run dev
```

### Option 2: Bun

```sh
bun install
bun run dev
```

The app runs locally at the URL shown in terminal (typically `http://localhost:5173` for Vite defaults).

## Available scripts

- `npm run dev` - start dev server
- `npm run build` - create production build
- `npm run preview` - preview production build locally
- `npm run lint` - run ESLint
- `npm run test` - run tests once
- `npm run test:watch` - run tests in watch mode

## Tech stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn-ui
- Vitest
